# 请求与汇报规则

明确要求优先于模板固定规则，其次是汇报场景规则和默认策略。目标页数指总页数。固定目录逐字保留并按顺序规划，不自动合并或改名。目标页数无法承载必选内容时返回 CONSTRAINT_CONFLICT，给出实际所需页数。

缺类型时依据材料关键词判别，低置信度使用 custom；缺听众只记录保守假设，不把推断当事实。缺页数按时长和内容密度估算；均未给出时按事实量规划。内容不足留出明确待补充项，禁止凑出成果。内容过量保留关键事实并拆页；固定页数冲突需要调整计划。

多份材料合并来源，保留位置；同指标不同数值先阻断生成，要求提供明确来源决议，不自动择新。请求示例及预期策略见 tests/fixtures/request_cases.json。
