# PPT 汇报制作 Skill

把汇报材料发给 AI，让它帮你做成一份可以继续修改的 PPT。适合工作汇报、项目进展和答辩。

需要使用能读取电脑文件、运行命令并联网安装软件的 AI 助手，例如 Codex 或 Claude Code。下面的操作都在 AI 助手的聊天窗口里完成。

## 第一步，安装

第一次使用时，把这段话复制给 AI 助手，等它完成安装和检查。

```text
请帮我安装并配置这个做 PPT 的 Skill
https://github.com/DANK1NG111/ppt-report-skill

装好后，请检查能不能正常生成 PPT，并告诉我结果。
```

以后使用时可以直接做 PPT。安装遇到问题，就让 AI 助手查看报错，说明还需要你做什么，再继续处理。

## 第二步，发材料，说明要求

把汇报材料发给 AI 助手。Word（`.docx`）、能选中文字的 PDF、Excel（`.xlsx`）、已有 PPT（`.pptx`）都可以，也可以直接粘贴文字。

有学校或公司的 PPT 模板，就一起发 `.pptx` 文件。没有模板也能做，会使用自带的简洁样式。需要放自己的照片，也一起发给它。

然后告诉它给谁看、大概讲多久、想做多少页。可以直接复制这段话，再换成自己的要求。

```text
请用 ppt-report-skill，把我发的材料做成一份工作汇报 PPT。
给部门同事看，讲 5 分钟，做 8 页左右。
有模板就用我发的模板，没有就用简洁样式。
材料里没有的数据请标出待补充，不要编造。
做完后检查每一页，把可以修改的 PPT 文件给我。
```

有必须保留的目录、数字或图片，也在这时告诉它。需要 PDF 或演讲备注，可以一起提出。

## 第三步，打开检查，需要改就直接说

你会得到一个 `.pptx` 文件，可以用 PowerPoint 打开，继续修改文字、表格和常见图表，图片也可以单独替换。

看完后，需要调整就继续告诉 AI 助手，例如下面这样。

```text
第 3 页太挤了，请拆成两页，保留原来的数据。
```

## 使用边界

- 扫描版 PDF 需要先转成文字；Excel 里的公式不会自动计算，建议提供已经确认的数值。
- 图片里的文字不会自动变成可编辑文字。
- macOS 和 Linux 已做过安装与生成测试；Windows 安装流程还没有实机测试。
